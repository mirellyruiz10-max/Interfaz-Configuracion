# Interfaz de Configuración de Página

Proyecto desarrollado en Java utilizando JOGL.

## Objetivo

Desarrollar una interfaz para la configuración de páginas que permita modificar los márgenes y cambiar la orientación de la página.

## Funciones

- Configurar margen superior.
- Configurar margen inferior.
- Configurar margen izquierdo.
- Configurar margen derecho.
- Cambiar orientación entre Vertical y Horizontal.
- Mostrar una vista previa de la página.
- Botón Reset para regresar los márgenes a 0 y la orientación a Vertical.

## Tecnologías utilizadas

- Java
- JOGL
- Java Swing
- Apache NetBeans
- Maven

## Funcionamiento

La aplicación muestra una vista previa de una hoja.

El usuario puede modificar los cuatro márgenes y observar los cambios en la vista previa.

También puede seleccionar:

- Vertical
- Horizontal

El botón Reset establece:

- Margen superior: 0
- Margen inferior: 0
- Margen izquierdo: 0
- Margen derecho: 0
- Orientación: Vertical

## Ejecución

1. Abrir el proyecto en Apache NetBeans.
2. Esperar a que Maven descargue las dependencias.
3. Realizar Clean and Build.
4. Ejecutar el proyecto.
